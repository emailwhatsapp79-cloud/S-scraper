On your phone

  1. Install Firefox for AndroidChrome cannot run these. Firefox can.
  2. Add TampermonkeyIn Firefox: menu → Add-ons → search Tampermonkey → Add.
  3. Make a new scriptTampermonkey → Dashboard → the + tab. Select everything in the box, delete it, paste. Ctrl+S or File → Save.
  4. Open SportyBet vFootballA dark SCREEN button sits at the bottom right. Tap it, then tap FIND.

On a computer

  1. Add Tampermonkey to Chrome or FirefoxFrom the browser's own extension store.
  2. Dashboard → + → paste → saveSame as above.

The numbers it screens on are yours to change — tap Odds inside the panel. They are saved in that browser.

If FIND comes back with nothing, be on the vFootball list page and let the games load first, then tap it again. If it still finds nothing, tap Copy diagnostics and send me what it copied — that tells me exactly what SportyBet returned and I can fix the reader in one go.
